A/B Test: 3 Blog Posts

Each post targets a different audience segment and emotional trigger. All three funnel to /get-help/ with UTM-tagged CTAs for attribution tracking.

Emotion: Discovery / "I've been overpaying"

30-Day Execution Timeline

Day 0
Publish & Configure

Deploy all 3 blog posts. Verify Meta Pixel fires on each. Set up UTM parameters. Create 3 ad sets in Facebook Ads Manager with Traffic objective. Upload ad creative.

Days 1–3
Learning Phase

Let all 3 ad sets run at $10/day each. Facebook is optimizing delivery — don't touch anything. Monitor for disapprovals or delivery issues only.

Days 4–7
First Data Check

Pull CPC, CTR, and blog-to-/get-help/ click rates. Identify early winner and laggard. No budget changes yet — need more data.

Days 8–10
Kill / Scale Decision

Kill lowest-performing ad set. Redistribute its $10/day to the top two (60/40 split). This is the critical inflection point.

Days 11–17
Optimize Top 2

Test 2 ad creative variants per surviving post. Adjust audience targeting if needed. Monitor /get-help/ submissions closely.

Days 18–21
Second Kill / Scale

Evaluate remaining 2 posts. If one is clearly winning, shift 70%+ budget to it. If both performing, keep split and test new audiences.

Days 22–30
Scale & Retarget

Launch Lookalike Audience (1%) from pixel data. Create retargeting campaign for blog visitors who didn't submit /get-help/. Consider increasing daily budget to $40–50 if CPL is under $30.
