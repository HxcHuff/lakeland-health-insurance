Florida routing gate

Confirm ZIP code and coverage type before leaving this site.

This router checks only whether a five-digit ZIP falls within Florida’s general 320–349 ZIP range and then shows the appropriate next-step links. It does not determine licensure, eligibility, plan availability, subsidy, network, formulary, or enrollment status.

Privacy: The ZIP code stays in this browser and is not submitted by this router or included in an analytics event.

Routing limits

  • Florida scope only.
  • No eligibility or plan recommendation.
  • No provider or prescription details collected.
  • External sites control their own privacy and enrollment workflows.

Official fallback destinations

If the ZIP is outside Florida or this site cannot verify the requested path, use HealthCare.gov for Marketplace coverage or Medicare.gov for Medicare information. Do not submit personal information to an unverified referral destination.
